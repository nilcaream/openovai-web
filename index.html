In daily use on real software development, by the team that builds it.

A small team of Claude Code sessions, on one machine.

One session is the Leader; the others are named Workers with one task each. Every session's identity is a directory on disk, not a process — so a session can be replaced at any time without losing the work.

What you get

  • A session is a directory, not a process.

    Every seat owns a desk: one Markdown file, written with a tool as the work moves. A conversation that fills up writes its desk and ends; a fresh one reads it and carries on. Nothing is compacted away.

    The Leader and the Workers →

  • One Leader, named Workers.

    The Leader hires, delegates, relays and settles what the instance may do; it does no project work. Workers do one task each and stop when it ships. Whatever one Worker says to another, the Leader hears.

    How the team works →

  • Permissions are cards on the page.

    A session that reaches for something unsettled stops on its panel with the command and its reason. Allow it once, deny it with a sentence, or always allow the shape — one rule per side of a compound command.

    Permissions and safety →

  • Only the server writes to a session.

    Every turn arrives in a frame the server sets, and nothing inside a message can close it. Who is calling a tool is a per-process secret the server minted, never a name a session could claim.

    Who is speaking →

  • A store with a memory of its own.

    recall finds by meaning, not by grep. remember supersedes rather than accumulates: a text that restates a record is refused naming it. Hard rules reach every session, the running ones included.

    Memory and knowledge →

  • The lifecycle is tools, not phrases.

    Full, idle, out of quota, parked: one server event each, one tool call back. The quota gate warns the team, then holds every turn until the window resets, and lets them go in order.

    The lifecycle →

  • Every session on one page.

    No terminals. Three columns, one stream, installable as a web app. The tab's icon rings while any panel waits for you, and the browser notifies you while you are somewhere else.

    The page →

  • A file is a tool.

    Three exports under plugins/ and a restart: a tool of your own, served to every session under the one rule the instance already has. No permission card, no registration.

    Plugins →

  • Self-contained, and it updates itself.

    An instance carries its own copy of the toolkit, and the Node.js and Claude Code it runs on are pinned per release and fetched for you, never taken from the system. ovai update takes the next release whole and leaves what is yours alone.

    Install and update →

The shape of it

The Leader's panel is in the middle, the Workers' either side. A panel is a head — a dot, the name, the model, the context in k, and what the session is doing — a transcript, and a text box. You can type on any of them; the Leader hears what you say to a Worker the same moment.

Why a handover, and not a summary

Resuming a conversation the model service has stopped holding costs most of it again at write price: measured at fourteen times an ordinary turn on a conversation of 40,000 tokens, and about twenty on a large one. So a full session is not resumed. It writes its desk, ends, and a fresh one reads the desk and carries on — in the same panel, with whatever was queued for it.

This is not a setting and there is nothing to turn on. It is the shape of the thing.

Built from what you already have

Two persona templates, project settings, an MCP server, a shell shim, a few Node tools and a small web page to host it all on. Nothing runs that you cannot read in an evening. Sixteen test suites on Node's own runner, and every check in them was watched going red before it was kept.

Where it stands

It is a product, and the team that builds it runs its own software development on it every day. The features are well-rounded; small bugs are possible, and they get fixed. The repository is open and there is no gate: use it, and tell us what you tried, what happened and what you expected — or send the fix.
