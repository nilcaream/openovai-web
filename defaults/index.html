The defaults

Everything an instance runs on has a value, and every value is one of two kinds: a setting with a default, or a number written in the code. This page is both lists — what you can change and where, then what you cannot, what each fixed value governs, and why it is fixed rather than a setting. Read it before asking for a knob: the reason a value is fixed is usually the answer.

The six keys read when present are honoured and nowhere else: the installer does not write them, the terminal does not ask for them, and ovai configuration does not print them. A value of the wrong shape falls back to the default for that key.

Models

A model is a word: an alias or a full name, a letter or digit then up to sixty-three letters, digits, dots, dashes or underscores. That is the whole check, at install and at hire alike, and there is no list behind it — nothing in the toolkit accepts one model by name or refuses another, on purpose: a workspace that may be installed on a model has to be able to hire onto it, and a list would be a second answer to what the account can run. A model the account has not got is refused by the harness at the first turn, not by the instance. The default for both seats is opus.

One model is not yours to pick: the store's judge, the small run that reads a remember against the records it holds and says whether it restates one. It runs on sonnet at medium effort with a minute to answer, fixed in the code, so that every workspace judges a record the same way. No seat is given an effort level; the harness's own default applies.

What cannot be changed

Every value below is written in the code and the same in every instance. The last column is why: a fixed value is a decision, and the decision is what you would be asking to reopen. The file named is where it lives, under lib/.
